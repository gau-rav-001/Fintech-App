# SmartFinance project audit

26 November 2026 · Local working tree of `Fintech-App` · Branch `main` · Base commit `c006ef3`

**Release decision — hold deployment from this checkout.** The frontend source is missing, the deployment configuration contains reusable credentials, and the repository includes populated account and chat data. The financial assistant also gives different budgets for two ways of writing the same salary.

## Verification and limits

The project uses React and Vite for the browser, Nginx for routing, Express and PostgreSQL for the API and persistence, and Redis for authentication state. The backend includes user, advisor, administrator, notification and AI routes. The advisor middleware checks active client relationships against the database, and the repository contains 19 service test files covering areas including advisor isolation and session handling.

| Check | Result |
|---|---|
| Production frontend build with temporary output | Failed with Node `MODULE_NOT_FOUND` for `vite/bin/vite.js`. Git and the HTML entry point independently establish the missing source. |
| Offline financial assistant smoke script | 9 of 9 prompts returned text. The script counts nonempty responses and does not fail the process for a missed prompt or assert numeric correctness. [Smoke script](backend/tests/testFinancialBrain.js) |
| Equivalent salary inputs | Confirmed a numerical discrepancy by invoking the same calculator used by chat. |
| Delivery automation | Neither [application](package.json) nor [backend](backend/package.json) package scripts define a test command. Add a reproducible command that checks expected values and exits unsuccessfully on failure. |

This audit covers the current working tree, including uncommitted changes. It does not establish the state of a deployed service. Database-backed tests, image builds, browser flows, email delivery, external AI calls and dependency advisory scanning were outside the executed checks. Existing delivery reports and compiled files were not used as proof of current behavior.

**Release gates.** Address credential and data exposure first. Then reconcile the frontend source and prove a clean build. Before release, demonstrate a clean database bootstrap and run authenticated user, advisor and AI workflows against it, including numeric assertions for the budget calculator.
